# 23 Theme

A dark, eye-friendly color theme for Visual Studio Code and Cursor.

## Features

- **Dark background** — Near-black (#050505) background for reduced eye strain
- **Semantic highlighting** — Clear syntax highlighting based on code semantics
- **Multi-language support** — JavaScript, TypeScript, JSX, TSX, JSON, Markdown, CSS, SASS, HTML, and more
- **Color palette:**
  - **Comments** — Teal (#2b8a6e), italic
  - **Variables** — Light cyan (#b9e7f7)
  - **Functions** — Beige (#d2c4a3)
  - **Strings** — Pink (#fa9fbc)
  - **Numbers** — Orange (#f19a62)
  - **let, var, const** — Bright blue (#25beff)
  - **Component tags (JSX/TSX)** — Teal (#00a584), bold
  - **TypeScript type / interface names** — Teal (#00a584); variables stay #b9e7f7
  - **import / export / from / flow** — Purple (#d670d8)

## Installation

1. Open the **Extensions** view in VS Code or Cursor
2. Search for **23 Theme** and install it
3. Select the theme via **File > Preferences > Color Theme** (or `Ctrl+K Ctrl+T`)
