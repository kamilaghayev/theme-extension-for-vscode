# 23 Theme

Qaranlıq fonlu, rahat göz üçün uyğunlaşdırılmış Visual Studio Code / Cursor tema.

## Xüsusiyyətlər

- **Qaranlıq fon** — Tam qara (#000000) fon, gözü yormayan
- **Semantic highlighting** — Kod semantikasına əsaslanan aydın vurğulama
- **Çoxdilli dəstək** — JavaScript, TypeScript, JSX, TSX, JSON, Markdown, CSS, SASS, HTML və s.
- **Rəng palitrası:**
  - **Şərhlər** — Teal (#00a584), italik
  - **Dəyişənlər** — Açıq mavi (#c2ebff)
  - **Funksiyalar** — Bej (#ded6b9)
  - **Sətirlər** — Çəhrayı (#f0a7bf)
  - **Rəqəmlər** — Narıncı (#fab387)
  - **let, var, const** — Tünd mavi (#718ebb)
  - **Komponent teqləri (JSX/TSX)** — Teal (#00a584), qalın
  - **TypeScript type / interface adları** — Teal (#00a584); dəyişən adlarına təsir etmir, dəyişənlər #c2ebff qalır
  - **import/export** — Magenta (#ff4fa3)

## Quraşdırma

1. VS Code / Cursor-da `Extensions` panelini açın
2. `23 Theme` axtarın və quraşdırın
3. `File > Preferences > Color Theme` (və ya `Ctrl+K Ctrl+T`) ilə temanı seçin
